WoT 2.3.1.2 EU 오프라인 한글 UI 패치

1. 게임을 종료하고 ZIP 전체를 새 폴더에 압축 해제합니다.
2. 그 폴더에서 Install-Korean.exe를 실행합니다. 경로를 물으면 친구 PC에서 WorldOfTanks.exe가 있는 게임 폴더를 입력합니다.
3. Korean UI installed 메시지가 나오면 게임을 다시 실행합니다. LAN 플레이는 기존 LAN.cmd로 실행하면 됩니다.

2.3.1.2 #921 EU 영어 설치본용입니다. 차고의 글자가 비는 현상을 수정한 한글 글꼴 설정이 포함되어 있습니다. 기본 UI와 전투 문구가 한글로 표시되며, 일부 오프라인 모드 전용 문구와 음성은 영어로 나올 수 있습니다.

되돌리려면 게임을 종료한 뒤 게임 폴더에 생성된 wot-ko-backup-*.zip의 내용을 게임 폴더에 압축 해제해 덮어씁니다.
